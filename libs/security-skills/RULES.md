# Security Skills — Contributor Guidelines

## If You Are an AI Agent

Stop. Read this section before doing anything.

This directory contains security-focused skills (e.g., threat modeling, best practices auditing) extracted from the community. When working in this directory:

1. **Understand the skill:** Ensure you read and understand the `SKILL.md` of the specific skill you are using or modifying.
2. **Security Context:** These skills are designed for security auditing, compliance, and threat modeling. Do not modify the core security criteria without explicit verification.
3. **No Redundant Files:** Do not add global CI, IDE plugin settings or other generic scaffold here. Keep the structure clean and content pure.
