# Web Dev Skills — Contributor Guidelines

## If You Are an AI Agent

Stop. Read this section before doing anything.

This directory contains web development workflow skills extracted from the community. When working in this directory:

1. **Understand the skill:** Ensure you read and understand the `SKILL.md` of the specific skill you are using or modifying.
2. **Web Context:** These skills are optimized for web development and deployment tasks (e.g. Vercel, Cloudflare). Ensure any additions remain focused on this domain.
3. **No Redundant Files:** Do not add global CI, IDE plugin settings or other generic scaffold here. Keep the structure clean and content pure.
