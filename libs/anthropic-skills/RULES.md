# Anthropic Skills — Contributor Guidelines

## If You Are an AI Agent

Stop. Read this section before doing anything.

This directory contains the official Anthropic skills adapted for our monorepo. When working in this directory:

1. **Understand the skill:** Ensure you read and understand the `SKILL.md` of the specific skill you are using or modifying.
2. **No Redundant Files:** Do not add global CI, IDE plugin settings or other generic scaffold here. Keep the structure clean and content pure.
3. **Core Philosophy:** Maintain the general-purpose nature of these official skills. Domain-specific additions should be carefully considered before modifying these standard templates.
